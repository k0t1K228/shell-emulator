# Shell Emulator

Эмулятор командной строки (UNIX-подобный шелл). Практическое задание №1, Вариант №21.

## Общее описание

Проект реализует консольный эмулятор,  имитирующий работу в UNIX-подобной
операционной системе: интерактивный режим (REPL), выполнение команд из
стартового скрипта и работу с виртуальной файловой системой (VFS),
которая целиком хранится в памяти и загружается из XML-файла.

Разработка ведётся поэтапно:

- **Этап 1. REPL** - минимальный интерактивный цикл с приглашением,
раскрытием переменных окружения и командами-заглушками. Выполнено
- **Этап 2. Конфигурация** - параметры командной строки, выполнение
стартового скрипта. Выполнено
- **Этап 3. VFS** - загрузка виртуальной файловой системы из XML,
обработка ошибок загрузки. Выполнено
- **Этап 4. Основные команды** - логика для `ls`/`cd`, команды `clear`, `date`, `tac`. В разработке
- **Этап 5. Дополнительные команды** - `chmod`, `rmdir`. Не начато

## Функции и настройки

### Параметры командной строки

| Параметр   | Назначение
|------------|--------------------------------------------------
| `--vsf`    | путь к XML-файлу виртуальной файловой системе   |
| `--script` | путь к стартовому скрипту с командами эмулятора |

Оба параметра необязательны. Если `--script` не указан, эмулятор
запускается в интерактивном режиме. При запуске всегда печатается
отладочная информация с переданными параметрами.

### Поддерживаемые команды

- `ls [аргументы]` - на текущем этапе печатает переданные аргументы.
- `cd [аргументы]` - на данном этапе заглушка без функций.
- `exit` - завершает работу эмулятора.

Любая нераспознанная команда выводит сообщение об ошибке.

### Раскрытие переменных окружения

Перед разбором введённой строки в ней раскрываются переменные окружения
реальной OC, например `$HOME` подставляется как реальный домашний
каталог пользователя.

### Стартовый скрипт

Файл со списком команд эмулятора (по одной на строку). Каждая строка 
выполняется по очереди, при этом на экран выводится и сама команда
(с приглашением, как будто её ввёл пользователь), и результат её
выполнения. При первой ошибке (нераспознанная команда) выполнение 
скрипта останавливается

### Виртуальная файловая система (VFS)

VFS описывается XML-файлом и целиком загружается в память при
запуске (изменить исходный XML-файл через эмулятор нельзя)

Формат:

```xml
<vfs>
	<directory name="имя_папки">
		<file name="имя_файла">содержимое_в_base64</file>
		<directory name="вложенная_папка">
			...
		</directory>
	</directory>
	<file name="файл_в_корне">содержимое_в_base64</file>
</vfs>
```

- `<directory name="...">` - папка, может содержать вложенные `<directory>`
и `<file>`.
- `<file name="...">` - файл, его содержимое закодировано в base 64.

Если файл VFS не найден или содержит некорректный XML -  эмулятор
сообщает об этом и продолжает работу без VFS.

## Сборка и запуск

Требования: Python3 (без внешних зависимостей).

Запуск в интерактивном режиме:

```bash
./run.sh
```

или

```bash
python3 src/main.py
```

Запуск с параметрами:

```bash
python3 src/main.py --vfs vfs/simple.xml --script scripts/demo.txt
```

### Тестовые сценарии (папка `scripts/`)
- `run_with_script.sh` - запуск только со стартовым скриптом.
- `run_with_vfs_and_script.sh` - запуск с VFS и стартовым скриптом.
- `run_vfs_minimal.sh` - загрузка пустой VFS.
- `run_vfs_simple.sh` - загрузка VFS с несколькими файлами.
- `run_vfs_nested.sh` - загрузка VFS с вложенностью 3+ уровня.
- `run_vfs_errors.sh` - проверка обработки ошибок загрузки VFS
  (битый XML и несуществующий файл).
- `demo.txt` - стартовый скрипт-пример, используемый во всех сценариях
выше; демонстрирует все реализованные команды и остановку при ошибке.

### Тестовые VFS (папка `vfs/`)

- `minimal.xml` - пустая VFS.
- `simple.xml` - несколько файлов на верхнем уровне.
- `nested.xml` - вложенность от 3 уровней.
- `broken.xml` - намеренно некорректный XML

## Примеры использования

Интерактивный режим:

$./run.sh
ilya@Ubuntu:~$ ls-la/tmp
ls:аргуенты:['-la','/tmp']
ilya@Ubuntu:~$ cd $HOME
cd:аргументы:['/home/ilya']
ilya@Ubuntu:~$ exit
Запуск со стартовым скриптом и VFS:
$./scripts/run_vfs_simple.sh
Отладочная информация:
Путь к VFS:./scripts/../vfs/simple.xml
Путь к стартовому скрипту:./scripts/demo.txt
VFS успешно загружена. Файлов в VFS:2
ilya@Ubuntu:$ ls -la/tmp
ls:аргументы:['-la','/tmp']
ilya@Ubuntu:$ cd $HOME
cd:аргументы:['/home/ilya']
ilya@Ubuntu:~$ неизвестная_команда
Ошибка:неизвестная команда:неизвестная_команда
Выполнение скрипта остановлено из-за ошибки.
